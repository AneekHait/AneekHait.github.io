# Aneek Hait - Data Analyst Portfolio

A modern, responsive personal portfolio website showcasing data analysis skills, BI projects, and professional experience.

## Features
- Responsive design optimized for desktop, tablet, and mobile
- Interactive visualizations and project showcases
- Professional work experience and skills sections
- Clean, modern UI with smooth animations
- Fast-loading static site

## Tech Stack
- **HTML5** - Semantic markup
- **CSS3** - Custom inline styles with design tokens and CSS Grid/Flexbox layouts
- **JavaScript** - Vanilla JS for interactive features, animations, and intersection observers
- **Google Fonts** - Professional typography (Fraunces, Space Grotesk, IBM Plex Mono)

## Project Structure
```
.
├── index.html          # Main portfolio page
├── assets/             # Static assets
│   └── css/
│       └── styles.css  # Custom styles
└── README.md           # This file
```

## Getting Started
### Local Development
Simply open `index.html` in your browser to view the site locally.

### Prerequisites
No build tools or dependencies required—this is a static site.
